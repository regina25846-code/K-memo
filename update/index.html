K-Memo

PC 메모 프로그램

텍스트·체크리스트 메모부터 달력·할 일까지 한 곳에서.
폴더별 잠금과 심층 암호화로 민감한 메모는 따로 보호하고,
조용히 트레이에 상주하며 바탕화면 위에 항상 떠 있는 데스크톱 메모장.

현재 버전v1.5.1
배포일2026-08-25
지원 환경Windows 64bit
01

다운로드

Windows 64bit
설치형 다운로드 K-Memo.Setup.1.5.1.exe 포터블 다운로드 K-Memo-1.5.1-portable.exe

설치형 자동 업데이트

실행 중 새 버전을 자동으로 감지합니다. 트레이 우클릭 → 프로그램 정보에서도 업데이트 확인이 가능합니다. 이 페이지에 다시 올 필요가 없습니다.

포터블 수동 갱신

자동 업데이트가 지원되지 않습니다. 새 버전이 나올 때마다 이 페이지에서 파일을 다시 받아야 합니다.

03

설치 방법

약 1분
STEP 1

설치형·포터블 중 선택
설치형은 자동 업데이트, 포터블은 압축 없이 exe 하나로 바로 실행됩니다.

STEP 2

Windows 보안 경고
“추가 정보” → “그래도 실행”을 누릅니다.

STEP 3

첫 실행 시 라이선스 키 입력
발급받은 키를 입력하면 인증 완료 후 바로 시작됩니다.

04

주요 기능

텍스트·체크리스트 메모

바탕화면에 붙여두는 자유형 메모와 할 일 체크리스트

즐겨찾기 탭

자주 쓰는 메모를 따로 모아 바로 접근

달력·할 일

날짜별 일정과 오늘 할 일을 한 화면에서 관리

폴더 잠금 + 심층 암호화

AES-256-GCM으로 민감한 메모를 폴더 단위로 보호

백업·복원

메모 데이터 자동 백업, 필요할 때 바로 복원

트레이 상주

백그라운드에서 조용히 대기, 트레이에서 바로 열기

스킨 4종

K-Music 스타일 테마로 화면 분위기 전환

자동 업데이트

프로그램 정보에서 업데이트 확인 클릭 한 번

05

라이선스 인증

최초 1회

K-Memo는 라이선스 키로 인증해야 사용할 수 있습니다. 아래 세 가지만 알아두면 됩니다.

키는 관리자에게 요청

첫 실행 시 뜨는 라이선스 키 입력 화면에 KMEMO-XXXX-XXXX-XXXX 형식의 키를 입력합니다. 키는 관리자에게 직접 요청해서 발급받습니다.

PC 1대에만 등록

하드웨어 기반 기기 식별로 라이선스 키 중복 사용을 막습니다. 다른 PC에서 쓰려면 별도 키가 필요합니다.

Windows 보안 경고

설치형 exe 실행 시 SmartScreen 경고가 뜰 수 있습니다. "추가 정보" → "그래도 실행"을 누르면 정상적으로 설치됩니다.
